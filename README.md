# Nail Salon Booking System

Booking system for a nail salon. Customers book appointments online,
the salon manages services, staff and schedule.

## Stack
- Java 21, Spring Boot, Spring Data JPA
- PostgreSQL 16 (Docker)
- Flyway for database migrations
- React + Vite (frontend)

## Running locally
1. `docker compose up -d`
2. `cd backend && ./mvnw spring-boot:run`
3. API at http://localhost:8080
